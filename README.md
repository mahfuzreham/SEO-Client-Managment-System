# SEO Client Management System

A Bootstrap and MySQL based SEO client management platform.

## Features
- Client dashboard
- On-page SEO tracking
- Off-page SEO tracking
- Keyword ranking monitor
- Backlink management
- PDF reports
- Multi-admin support
- Telegram and WhatsApp notifications

## Tech Stack
- PHP 8
- Bootstrap 5
- MySQL
- ApexCharts
